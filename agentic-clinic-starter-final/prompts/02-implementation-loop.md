# Sprint Implementation Loop

Precondition:
Business Owner approved current Sprint Plan.

For each approved Sprint Backlog item:

1. confirm it exists in backlog;
2. confirm Ready Gate passed;
3. review acceptance criteria;
4. implement smallest correct solution;
5. add/update tests;
6. run tests;
7. review against business invariants;
8. fix ordinary defects;
9. update docs;
10. update BUILD_LOG.md;
11. mark Done only when Definition of Done is satisfied.

Every discovered work item must first enter backlog.

Do not declare early milestone.

When all approved Sprint Backlog items are Done:
run milestone review.
